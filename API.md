# Архитектура Базы Данных и APIconfigs:



## Структура Базы Данных (Entities)    поля бд:



### Configs (Конфигурации)  

*   **id**: Номер конфига

*   **subscription_id**: Номер конфига


*   **is_test**: Тестовый (boolean)     

*   **server_id**: Номер сервера

*   **protocol**: Протокол (byte) (маска)        



### Servers (Серверы)     

*   **id**: Server ID

*   **ip**: IP адресservers:

*   **country**: Страна

*   **ssh_keys_hash**: Хэш SSH ключей  

*   **monthly_cost**: Стоимость в месяц

*   **hostname**: Имя хоста         

*   **max_configs**: Максимальное количество конфигов

*   **status**: Статус (активный, деактивированный, готовится к деактивации, тех. проблемы) 

*   **protocol**: Поддерживаемый протоколы, маска (001) первые два хз последний amneziawg


### Users (Пользователи)

*   **user_id**: Telegram ID (BigInt)

*   **username**: Имя пользователя в TG    

*   **invited_by**: ID реферала (кто пригласил)

*   **can_take_test**: Может ли брать тестовый период (boolean)  

*   **rank**: Ранг (новый, пользующийся) статус новый - пока не купил первую подписку за деньги



### Carma (Карма)    
*   **user_id**: ID пользователя

*   **total_points**: Кол-во очков всего       

*   **active_points**: Кол-во активных очков

*   **last_updated**: Время последнего обновления   



### Carma Events (События Кармы) 

*   **id**: ID события

*   **user_id**: ID пользователя       

*   **amount**: Кол-во очков

*   **is_positive**: Тип (+/-) (boolean)   

*   **reason**: Причина

*   **created_at**: Время создания  



### Applications (Заявки)      

*   **id**: ID заявки

*   **user_id**: ID пользователя  

*   **subscription_id**: ID подписки (если продление)

*   **amount**: Стоимость заявки      

*   **currency**: Валюта

*   **type**: Тип (новая, на продление)    

*   **status**: Статус (на рассмотрении, ожидание оплаты, проверка оплаты)

*   **created_at**: Дата подачи       



### Subscriptions (Подписки)  

*   **id**: ID подписки

*   **user_id**: ID пользователя   

*   **start_date**: Дата оформленияcarma:    

*   **end_date**: Дата истечения

*   **cost**: Стоимость подписки 


## Описание API   



### Configs API      

*   **Добавить конфиг**

*   **Удалить конфиг**     

*   **Изменить конфиг**

*   **Получить конфиг(и)**:      

    *   По ID конфига

    *   По ID пользователя  

    *   По ID сервера

    *   По стране       

    *   По ID подписки


### Users API

*   **Добавить юзера**   

*   **Удалить юзера**

*   **Изменить юзера** (пустые поля не менять)     

*   **Получить юзера**:

    *   По ID подписки    

    *   По ID конфига

    *   По ID пользователя       

    *   По username   

*   **Получить список юзеров**:

    *   Сортировка по карме (активной/пассивной)    

    *   Фильтрация по наличию подписок

    *   *Поддержка пагинации (limit, offset)*  

*   **Получить количество юзеров**


### Carma API

*   **Получить строку кармы** (по user id)

*   **Получить количество активных баллов**

*   **Получить количество общих баллов** 



### Carma Events API         

*   **Добавить событие**: Автоматически обновить очки пользователя

*   **Удалить событие**: Просто удаление записи      

*   **Удалить старые события**: Позднее N дней или определенной даты

*   **Очистка истории**: Удалить все, кроме последних N штук   



### Servers API    

*   **Добавить сервер**

*   **Удалить сервер**: Автоматически удалить все связанные конфиги 

*   **Остановить сервер**: Автоматически сменить сервер у всех конфигов

*   **Запустить сервер**  
*   **Изменить данные сервера**: (кроме IP, страны и ID)

*   **find_best_server**: Получить сервер по стране с наименьшей нагрузкой (для балансировки)      



### Subscriptions API        id конфига

*   **Удалить подписку**

*   **Продлить подписку**: На N дней (без начисления кармы)subscriptions      

*   **Продлить подписку**: На месяц за счёт баллов кармы

*   **Создать подписку**: На месяц за счёт баллов кармы      

*   **revoke_expired**: Автоматическое отключение всех истекших подписок

*   **Получить подписки**:   

    *   Все подписки пользователя

    *   Подписки, истекающие через N дней     

    *   По ID подписки

    *   *Поддержка пагинации (limit, offset)*       



### Applications API     

*   **Одобрить заявку**:

    *   *Атомарная транзакция*: Создать/продлить подписку -> Начислить карму -> Создать событие кармы     

*   **Получить заявки**:

    *   Все   

    *   По типу

    *   По статусу  

    *   *Поддержка пагинации (limit, offset)*

*   **Удалить заявку**  

*   *Поддержка ключей идемпотентности*
